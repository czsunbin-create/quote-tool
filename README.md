# 装修报价核对器

双击 index.html 即可在现代浏览器使用。index.html、style.css、codes.js 和 app.js 放在同一目录即可运行，无需安装、登录或联网。

填写面积和总价，选择半包或全包，勾选已明确包含的项目，再点「核对这份报价」。每平方米单价等于总价除以面积。当地参考区间可留空；若要判断高低，请同时填写当地同模式、同材料档次、同面积口径的参考单价上下限。参考总价上下限分别等于面积乘对应单价，边界计入区间。未勾选项目会列为待确认项。

免费版可计算和展开前 3 条清单。点击「解锁全部」并输入正确口令即可查看 30 条。点击「切换免费版」恢复免费状态。浏览器允许时会在本地记住解锁状态。

## 更换解锁码

在 codes.js 中维护解锁码列表。移除的码在加载新版后失效。静态源码可读，这种付费墙适合人工发码和轻量访问控制。网页本身不处理收款。

## 部署到 Vercel（3 步）

1. 将 index.html、style.css、codes.js 和 app.js 放在 Git 仓库根目录并提交。README 与销售材料可留在本地。
2. 在 Vercel 新建项目，导入该仓库，框架选择 Other，根目录选择这三个文件所在目录。
3. 留空构建命令，输出目录设为当前目录 `.`，点击 Deploy，打开生成的地址试算。

Netlify 同样可作为静态目录托管。
